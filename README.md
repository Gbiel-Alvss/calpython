# Calculadora Jurídica — Tema 245 do TST

Aplicação desenvolvida em Python para auxiliar no cálculo de períodos relacionados ao Tema 245 do Tribunal Superior do Trabalho (TST), com suporte ao tratamento de feriados e geração de relatórios em PDF.

## Sobre o projeto

Este projeto foi desenvolvido em Python a partir de uma necessidade apresentada por um profissional da área jurídica, que solicitou a criação de uma aplicação para auxiliar em cálculos relacionados ao Tema 245 do Tribunal Superior do Trabalho (TST).

A aplicação foi desenvolvida com o objetivo de automatizar cálculos, considerar feriados e facilitar a geração de relatórios em PDF, proporcionando uma utilização mais organizada e prática.

Após o desenvolvimento, o projeto foi conferido e aprovado pelo profissional que solicitou sua criação, contribuindo para a validação de sua utilização no contexto proposto.

O projeto também representa uma experiência prática de desenvolvimento de software a partir de uma necessidade real, envolvendo levantamento de requisitos, implementação de funcionalidades e organização de resultados.


## Funcionalidades

* Interface gráfica para entrada de dados.
* Cálculos relacionados ao Tema 245 do TST.
* Tratamento de feriados.
* Geração de relatórios em PDF.
* Organização e apresentação dos resultados.

## Tecnologias utilizadas

* **Python** — linguagem principal do projeto.
* **Tkinter** — desenvolvimento da interface gráfica.
* **Programação Orientada a Objetos** — organização e estruturação do código.
* **PDF** — geração de relatórios dos resultados.

## Como executar

### Pré-requisitos

* Python 3 instalado.
* Git instalado, caso o projeto seja clonado do GitHub.

### Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Acesse a pasta do projeto:

```bash
cd calculadora-juridica
```

Instale as dependências, caso existam:

```bash
pip install -r requirements.txt
```

Execute a aplicação:

```bash
python main.py
```

> Os nomes dos arquivos e comandos devem ser ajustados conforme a estrutura real do projeto.
